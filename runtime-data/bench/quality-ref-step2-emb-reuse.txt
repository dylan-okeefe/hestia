The orchestrator chooses which agent responds by interpreting the resident’s message and matching it to the agent whose responsibilities and context are most relevant. If the message concerns a scheduled obligation, the scheduling agent is likely selected; if it depends on remembered household facts, the long-term memory agent is consulted; if it requires continuity from recent conversation, short-term memory is used. The orchestrator may also gather context from multiple agents before composing a single reply, so the response is not just routed to one agent but assembled from the most appropriate sources.

This selection process is designed to be predictable and conservative. Rather than choosing the agent that produces the most interesting or elaborate answer, the orchestrator prioritizes the agent that can reliably access the needed information and act on it. For household tasks, the correct agent is often the one tied to the relevant obligation, fact, or memory, not the one that can generate a more creative response.

Reliability is emphasized over cleverness because household assistance depends on trust and consistency. A missed reminder, incorrect task assignment, or forgotten obligation can have real consequences, such as a resident missing an appointment or a household task going undone. A plain but dependable response is therefore preferable to a witty or sophisticated one that might fail to deliver the needed action.

In short, the orchestrator’s goal is to make the right agent respond with the right context at the right time. Cleverness may improve presentation, but reliability determines whether the assistant is actually useful.
