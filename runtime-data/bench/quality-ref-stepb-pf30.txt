The orchestrator chooses an agent by first interpreting the resident’s message and identifying the task type, such as a reminder, household coordination request, factual question, or scheduling need. It then considers which agent is best suited to handle that task based on the agent’s role, available tools, and access to relevant context. For example, an agent responsible for obligations and timing would be preferred for a reminder, while a memory-focused agent might be used when the answer depends on stored household facts.

The orchestrator also gathers context before routing the response. This includes short-term memory from recent interactions, long-term facts about household members or preferences, and the current schedule of obligations. By combining these sources, the orchestrator can determine not only which agent should respond, but also what information that agent needs to give a correct and useful answer. This helps prevent mismatches, such as sending a reminder to the wrong person or at the wrong time.

Reliability is emphasized over cleverness because household assistance depends on trust and predictability. A resident may rely on reminders, schedules, and coordinated tasks to manage daily life, so a missed or incorrect response can cause real inconvenience or harm. A plain, accurate reminder is more valuable than a witty or creative one that fails to deliver the needed information. In this setting, the assistant’s main job is to be dependable, consistent, and safe rather than impressive.
