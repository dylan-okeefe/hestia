The orchestrator chooses which agent responds by interpreting the resident’s message and matching it to the agent whose responsibilities and context are most relevant. It considers the agent’s short-term memory, long-term facts, and scheduled obligations to determine whether the request concerns a household task, a reminder, a stored fact, or a coordination issue. The goal is to route the message to the agent best equipped to handle it accurately.

This selection process is practical rather than speculative. If a resident asks about a scheduled obligation, the orchestrator should prioritize the agent that maintains the schedule and can confirm or update it. If the message depends on a long-term household fact, it should route to the agent with access to that fact. The orchestrator therefore uses relevance, responsibility, and available context as the main decision criteria.

Reliability is emphasized over cleverness because household assistance depends on dependable execution. A missed reminder, incorrect task assignment, or forgotten obligation can have real consequences for the residents. A plain, correct response that fulfills the task is more valuable than an inventive answer that risks misunderstanding or failing to act.

In this setting, trustworthiness is the primary quality. The assistant should behave consistently, preserve important information, and follow through on obligations.
