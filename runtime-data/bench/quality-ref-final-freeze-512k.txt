The orchestrator chooses which agent responds by interpreting the resident’s message and matching it to the agent whose responsibilities and context are most relevant. If the message concerns a scheduled obligation, such as a reminder, appointment, or household task, the orchestrator likely routes it to the agent that maintains the schedule and obligations. If it involves a stable household fact, such as a preference, address, or long-term detail, it may route to the agent responsible for long-term facts. If the message depends on recent conversation or immediate context, the short-term memory agent may be selected.

The orchestrator also gathers the relevant context before streaming a reply. This means it does not simply pick an agent and let it answer in isolation; it retrieves the information that agent needs to respond correctly. For example, a reminder agent may need the current time, the resident’s calendar, and any recent changes to the task. A fact agent may need the stored household information and possibly the conversation history to understand what the resident is asking. This context-gathering step helps prevent wrong or incomplete answers.

Reliability is emphasized over cleverness because the assistant’s main value is in doing dependable household coordination. A missed reminder, wrong task assignment, or forgotten obligation can have real consequences, such as a resident missing an appointment or failing to complete an important household task. A plain but correct response is safer than a witty or speculative one. In this setting, the system should prioritize accuracy, consistency, and predictable behavior over creative or impressive replies.
