The orchestrator chooses which agent responds by interpreting the resident’s message and matching it to the agent whose responsibilities and context are most relevant. It considers the type of request—such as a reminder, household task, schedule change, or factual question—and selects the agent that maintains the appropriate short-term memory, long-term facts, or obligations. This routing step is not meant to be creative; it is meant to be predictable, so the assistant can consistently direct each request to the agent best equipped to handle it.

After choosing the agent, the orchestrator gathers the relevant context needed for a reliable response. That context may include recent conversation history, stored household facts, scheduled obligations, or task-specific details. By assembling this information before streaming a reply, the assistant reduces the chance of missing an important detail, such as a time, location, preference, or dependency. The goal is to make the response grounded in the household’s actual state rather than relying on assumptions.

Reliability is emphasized over cleverness because household assistance depends on trust and consistency. A missed reminder, incorrect schedule, or forgotten obligation can have real consequences, while a plain but accurate response is usually acceptable. Cleverness can introduce ambiguity, unnecessary complexity, or unexpected behavior, which is risky in a system responsible for coordination. In this setting, the assistant should prioritize doing the right thing every time over sounding impressive.
