The orchestrator chooses an agent by first interpreting the resident’s message and identifying the task type, such as a reminder, household coordination request, factual question, or scheduling need. It then checks which agent is best suited to handle that task based on the agent’s role, available tools, and access to relevant context. For example, an agent responsible for obligations would be preferred for time-sensitive tasks, while a memory or facts agent would be preferred for questions about stored household information.

The orchestrator also gathers context from short-term memory, long-term facts, and the schedule of obligations before selecting the response path. This helps it avoid choosing an agent that lacks the necessary information or would produce an incomplete answer. If multiple agents could respond, the orchestrator favors the one with the most direct access to the relevant data and the clearest responsibility for the task.

Reliability is emphasized over cleverness because household assistance depends on trust and consistency. A resident may rely on reminders, appointments, and task coordination as part of daily life, so a missed or delayed reminder can cause real inconvenience or harm. A plain, accurate, and dependable response is therefore preferable to a more creative or sophisticated one that risks misunderstanding, omission, or failure.
