The orchestrator chooses which agent responds by interpreting the resident’s message and matching it to the agent whose responsibilities and context are most relevant. It considers the type of request, the household task involved, and the information each agent maintains, such as short-term memory, long-term facts, and scheduled obligations. If the message concerns a reminder, appointment, or household duty, the orchestrator routes it to the agent that owns that obligation or has the necessary context to answer accurately.

The selection process is not just about picking the most fluent or creative response. It is about choosing the agent that can provide the correct, timely, and dependable answer. The orchestrator gathers relevant context before replying, which helps ensure the response reflects known facts, current schedules, and recent interactions. This makes the system more like a coordinated household manager than a general chatbot.

Reliability is emphasized over cleverness because household assistance depends on trust. A resident may rely on reminders, task tracking, and accurate coordination of daily obligations. If the assistant is witty or elaborate but misses a reminder, gives outdated information, or confuses responsibilities, the practical value of the system drops sharply. A plain but correct reminder is more useful than a clever response that fails to act on the resident’s needs.

In this setting, reliability means predictable behavior, clear routing, and consistent handling of obligations. The goal is not to impress the user with sophisticated language, but to support the household safely and dependably. A missed reminder can cause real inconvenience, so the orchestrator prioritizes accurate agent selection and faithful context use over stylistic flair.
