# v0.14.0 — Browser Fetch Hardening and Write Recovery

2026-06-15

Reconstructed from the [`CHANGELOG.md`](../../CHANGELOG.md) `[0.14.0]`
section; no release notes were written at the time.

## What's new

### Browser automation

- **Shared authenticated fetch helper** — `hestia.tools.browser.fetch.fetch_url`
  provides a single Playwright-based path for `browser_get` and
  `browser_get_links`, with persistent session reuse, per-domain rate
  limiting, and stealth context injection.
- **Structured result categories** — fetches return explicit `SUCCESS`,
  `BLOCKED`, `NOT_FOUND`, `TIMEOUT`, or `TRANSIENT_OTHER` categories and
  embed `[CATEGORY: <name>]` in failure text so retry logic no longer
  re-guesses from human-readable strings.
- **Honest page classification** — login/challenge detection is driven by
  the final URL and page title first; body-text triggers require login
  phrases to dominate the page, so listings that merely say "Log in to
  apply" are no longer silently discarded.
- Documented the `browser_login` → `browser_get` flow with session storage
  and health-check expectations.

### File writing and recovery

- **Truncated-write recovery** — the quality monitor detects oversized
  unclosed XML `write_file`/`append_to_file` blocks, drops the incomplete
  trailing line, writes the safe prefix, and tells the model where to
  resume.
- **Chunked large-file protocol** — large files are written as an initial
  `write_file` followed by `append_to_file` sections.
- Byte-for-byte seam test covering recovery of a file truncated mid-line.

### Tooling reliability

- Tool-result classifier (`ToolResultCategory`) distinguishing transient
  failures from permanent blocks and 404s.
- Retry policy wiring: capped identical retries, fail-fast on blocked/404
  URLs, per-attempt and total time budgets for timeouts.
- XML tool-call repair for `<parameter=arguments>` direct calls and
  unclosed tags from small/reasoning models.

### Hygiene and diagnostics

- Regression fixture suite of real model failures (malformed XML tool
  calls, network failures), with a scrubber that redacts emails, IPs,
  home paths, platform tokens, session cookies, and high-entropy values
  before fixtures are committed.
