# v0.12.2 — Job Workflow Reliability Patch

2026-05-27

Patch release focused on job-alert workflow reliability. Fixes artifact
passing, URL extraction, browser anti-detection, and Cloudflare session
management.

## What changed

- **Artifact passing** — downstream workflow nodes now receive full artifact
  content instead of truncated previews when results exceed `max_inline_chars`.
- **URL extraction fallback** — when the LLM fails to extract a job URL, the
  executor scans the email body directly for job-related URLs (LinkedIn,
  Indeed, ZipRecruiter, Glassdoor, Dice, Built In) including encoded tracking
  redirects.
- **Browser anti-detection** — additional stealth args and enhanced init scripts
  for `navigator.plugins`, `window.chrome.runtime`, and `navigator.languages`.
- **Cloudflare handling** — `browser_get` returns `[BLOCKED] ...` instead of
  challenge-page HTML so downstream nodes can fall back gracefully.
- **Inference timeouts** — default HTTP timeout raised from 120s to 300s;
  `max_tokens=4096` and `reasoning_budget=512` for all inference nodes.
- **New scripts** — `warmup_site_session.py` for headed browser warmup,
  `test_workflow_email.py` for IMAP UID-specific workflow testing.
- **New guide** — `docs/guides/browser-sessions.md` covers warmup, login, and
  troubleshooting.
