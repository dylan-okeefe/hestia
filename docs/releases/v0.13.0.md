# v0.13.0 — Browser Sessions, Workflow Polish, and Security Hardening

2026-06-06

Major release. Ships the browser session dashboard, headed browser streaming,
workflow editor polish, quality monitor, and extensive security hardening.

## What's new

### Browser Sessions
- **Session dashboard** — list, manage, and health-check persistent browser
  sessions per-domain from the web UI.
- **CDP screencast streaming** — interact with a headless browser via the web
  dashboard: click, type, scroll, with live screen capture.
- **Headed streaming** — real browser window for bot-blocking sites while
  streaming the screen to the dashboard.
- **playwright-stealth** — comprehensive anti-detection (WebGL spoofing,
  navigator masking, automation flag removal).
- **Domain normalization** — `www.` variants deduplicated automatically.

### Workflows
- **Email triggers** — incoming IMAP emails can trigger workflow executions.
- **Test any version** — execute inactive workflow versions for validation.
- **Execution drill-down** — inspect per-node results, token usage, and timing.
- **Responsive editor** — mobile layout, viewport-aware node placement,
  sticky toolbar, and debounced undo snapshots.

### Tools
- `edit_file` — surgical str-replace file modifications.
- `glob` and `grep` — filesystem search builtins.
- Write-guard — refuses to overwrite existing files.
- `rollback_turn` — per-turn checkpointing with create/restore/discard.
- `repair_json` — recovers malformed tool-call arguments.

### Orchestrator
- **Quality monitor** — detects repetition and circular reasoning, injects
  automatic corrections.
- **Thinking-budget abort** — mid-stream cancellation with commit nudge.
- **Streaming hardening** — defensive dict access, aligned malformed-argument
  handling.
- **Reasoning cap** — 2000-char limit on the done path.

### Security
- SSRF hardening with IPv4-mapped-IPv6 normalization and CGNAT blocking.
- Webhook replay protection via bounded LRU signature cache.
- Slot-manager double-eviction race fix.

### Web Dashboard
- Session titles for Telegram group chats.
- Debug login for development (configurable bypass).
- Auth race fixes, global fetch timeout, dark mode, shared CSS system.

## Upgrade notes
- New dependency: `playwright-stealth` for browser anti-detection.
- New Alembic migration: `title` column on `sessions` table.
- `web.debug_login` defaults to `False`; set to `True` only for local
  development.
