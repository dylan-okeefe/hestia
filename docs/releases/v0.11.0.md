# Hestia v0.11.0 — Release Notes

**Release date:** 2026-04-30

## Highlights

Security hardening, structural consolidation, streaming inference, and performance optimizations. Net reduction of ~2,500 lines of dead weight.

## Security
- `allowed_roots` defaults to `[]` (deny-all) instead of `["."]`.
- `EmailConfig.__repr__` masks `password`; `TelegramConfig.__repr__` masks `bot_token`.
- `TrustConfig.developer()` emits a `logger.warning()` on use.
- `hestia doctor` fails when `trust.preset == "developer"` outside a dev environment.
- Terminal tool blocks dangerous patterns (`rm -rf /`, disk overwrite, fork bombs).
- `TrustConfig.blocked_shell_patterns` allows operator customization of blocked commands.
- Egress audit logs strip query parameters before persisting URLs.
- Tool calls per turn are capped at `PolicyConfig.max_tool_calls_per_turn` (default 10).
- `curl_cffi` fallback is opt-in via `HestiaConfig.use_curl_cffi_fallback` (default `False`).

## Streaming Inference
- `InferenceClient.chat_stream()` — async generator consuming SSE events from llama-server.
- `StreamDelta` type carrying content, reasoning, tool-call chunks, and token usage.
- Orchestrator streaming branch — accumulates deltas and reconstructs `ChatResponse` for downstream handling.
- Telegram progressive delivery — first chunk as new message, then rate-limited edits.

## Performance
- `ContextBuilder.warm_up()` — pre-computes join overhead during startup.
- `InferenceClient.tokenize_batch()` — counts tokens for N messages in a single HTTP round-trip.
- Conditional copy in `_strip_historical_reasoning` — only allocates when reasoning is present.
- `_count_body` cache key hardened with `hash(tuple(...))`.

## Config & CLI
- `HestiaConfig` sub-groupings — `CoreConfig`, `PlatformConfig`, `FeatureConfig` organize 19 nested objects.
- CLI auto-discovery via `pkgutil` — no more manual import lists.
- `hestia audit run --strict` returns exit code 1 on any failure/warning.
- `hestia history` command for session/conversation retrieval.

## Reliability
- `SlotManager._pick_lru_victim` uses single batch query.
- Concurrent tool dispatch catches exceptions per-tool.
- Per-session token-bucket rate limiter (`SessionRateLimiter`).
- Email adapter async safety — all IMAP calls wrapped in `asyncio.to_thread`.

## Structural
- Collapsed `CoreAppContext` + `FeatureAppContext` + `CliAppContext` into single `AppContext`.
- `InferenceClient` consolidated with single `_request()` helper.
- Skills subsystem removed entirely (~1,500 lines deleted).
- Reflection subsystem slimmed from 752 → 339 lines.
- Style subsystem slimmed from 899 → 329 lines.

## Upgrade Notes
- Run `hestia doctor` after upgrade to verify prerequisites.
- No database migrations required.
