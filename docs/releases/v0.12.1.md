# v0.12.1 — Workflow Editor Hotfix

2026-05-21

Immediate follow-up to v0.12.0. Resolves critical UX blockers discovered
within hours of the release, plus SPA routing and workflow-editor polish.

## What changed

- **SPA routing** — FastAPI now serves `index.html` for all non-API paths,
  eliminating 404 errors on page refresh.
- **Workflow editor canvas** — fills available viewport height; toolbar stays
  visible while scrolling.
- **Node defaults** — new nodes default to `tool_call` instead of the invalid
  `'default'` type.
- **Version loading** — opening a workflow now loads the most recent saved
  version when none is active.
- **Test runs without activation** — backend accepts an optional `version_id`;
  frontend automatically tests the latest version.
- **Sticky toolbar + sidebar** — editor toolbar and 320px version sidebar
  provide persistent navigation while editing.
- **Platform-filtered send_message** — target user dropdown filters by the
  selected platform and uses the platform-native ID.
