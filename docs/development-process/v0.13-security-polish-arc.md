# v0.13 Security + Polish Arc

Comprehensive review remediation based on Opus/Copilot audit (2026-06-04).
Goal: land on develop, then cut a clean release to main for the Reddit post.

## Honest Evaluation Summary

Hestia is genuinely impressive for a solo project: 1,694 tests, strong security intent,
ambitious web UI with workflows, memory, multi-platform support, and a thoughtful trust model.
The codebase shows clear architectural vision (AppContext composition root, SQLAlchemy Core,
separated persistence, policy engine).

Where it strains:
- **Authorization is inconsistent.** Some routes enforce owner/admin, others don't. This is
the #1 blocker for a public release with a multi-user trust model.
- **Fast growth outpaced consolidation.** Dead code modules, duplicate tool registrations,
and diverged file pairs suggest aggressive feature velocity without cleanup passes.
- **Web UI state management is fragile.** Error boundaries conflate unrelated failures,
useApi lacks cleanup guards, and the workflow editor has UX friction that will frustrate
users trying to build non-trivial automations.
- **Documentation drift.** The files new users read first (environment variables guide,
release notes) contain stale or incorrect information.

Overall verdict: **solid enough to post**, but fix the auth gaps and a few UI crashes
before calling it a release. The rest can ship as "known rough edges" in a beta.
